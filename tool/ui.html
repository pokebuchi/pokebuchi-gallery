写真を入れる

ここに写真をまとめてドロップ

クリックして選ぶこともできます（複数まとめてOK）

未割り当て 0 枚 写真をクリックしてから、下の作品をクリック

作品を追加する

BASEに出品したものを、写真待ちのリストに加えます。

連結フレームはカード番号が1つに決まらないため、パック名とナンバーは使いません。
追加すると連結フレームの一番上に入ります。順番はカテゴリタブで変えられます。

作品をタップすると、名前や商品URLを直したり、削除したりできます。
写真を差し替えるときは、上に写真をドロップしてから作品をタップしてください。

ここで並べた順番が、そのままギャラリーの並び順になります。
▲▼ で上下に動かし、パックは 移動先 から別のカテゴリへ移せます。
連結フレームだけは、パックではなく作品そのものを並べ替えられます。

作品を直す

スマホから使うには
  1. iPhone を家と同じ Wi-Fi につなぐ
  2. Safari のアドレス欄に itsuki.local:8080 と入力
  3. 画面下の共有ボタン（□に↑） → 「ホーム画面に追加」

以後はホーム画面のアイコンをタップするだけで開けます。
パソコンの電源が入っていれば、いつでも使えます。
